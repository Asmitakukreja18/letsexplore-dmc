# Let's Explore - Tours & Travel Web Application

Welcome to **Let's Explore**, a feature-rich tours and travel booking web platform.

## Features
- **Interactive Tour Booking & Exploration**: Discover curated holiday packages, custom itineraries, and deal listings.
- **AI Travel Assistant**: Interactive AI travel itinerary planner.
- **Wishlist & Comparison Tool**: Save tours to wishlist and compare itineraries side-by-side.
- **User Reviews & Guides**: Detailed destination guides (e.g. Turkey Guide) and community reviews.
- **Backend Management**: Node.js/Express admin dashboard for managing packages, leads, and bookings.

## Project Structure
- Frontend: HTML5, Modern CSS, Vanilla JavaScript
- Backend: Node.js, Express, SQLite database (`backend/server.js`)

## Getting Started
1. Run backend server:
   ```bash
   cd backend
   npm install
   node server.js
   ```
2. Open `index.html` or `home.html` in your browser.
